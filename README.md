# 🚬 흡연 여부 판별 데이터 분석 프로젝트

본 프로젝트는 건강검진 데이터를 바탕으로 흡연 여부에 영향을 미치는 주요 변수를 탐색하고 시각화한 미니 프로젝트입니다.

## 📊 프로젝트 목표
- 흡연자와 비흡연자 간의 생체 지표(Hb, BMI 등) 차이 분석
- 변수 간 상관관계 파악 및 시각화
- 데이터 전처리 및 이상치 처리 프로세스 정립

## 🛠️ 사용 기술 및 라이브러리
- **Language**: Python
- **Libraries**: Pandas, Numpy, Matplotlib, Seaborn
- **Tools**: VS Code

## 📁 데이터 구조
- `data/raw`: 원본 데이터 (smoking_health_data.csv)
- `src/viz.py`: 시각화 공통 모듈
- `analysis.py`: 메인 분석 

## 📈 데이터 분석 결론

가설 1: 흡연자/비흡연자에서 충치 “발생 비율”이 실제로 다르다.(χ² 검정)

가설 2: 흡연자와 비흡연자의 헤모글로빈 평균은 유의하게 차이가 나며, 이 차이는 연령대별 분석에서도 관찰된다.

가설 3: 나이와 BMI를 통제했을 때, 흡연자는 비흡연자 대비 TG/HDL 비율이 약 39.4% 높다.

가설 4: BMI가 1만큼 증가할 때마다 흡연자일 오즈가 약 7.8% 증가한다(OR=1.078).

가설 5: 요단백은 흡연 여부에 따른 유의한 차이를 확인하지 못했다. 크레아티닌은 흡연자에서 높게 관찰되나,
            흡연자 집단의 남성 비율이 높은 것으로 추정되기에 (키·체중 증가 포함) 성별 교란 가능성이 크다.
            따라서 추가적인 데이터 및 성별을 통제한 추가 분석이 필요하다.

## 🔎 인사이트 정리 

1. 흡연의 영향은 구강처럼 직접 닿는 부위부터 시작해,  점차 대사 이상이나 신장 기능 저하 같은 전신적 위험으로 확산된다.

---
2. BMI는 흡연 여부에 대해 통계적으로 유의한 예측 변수이지만 (가설 4, P<0.05), 설명력(Pseudo R²=0.0121)이 매우 낮아
    실제로는 BMI보다 환경·행동 요인이 흡연을 훨씬 강하게 결정하는 것으로 보인다. 
    흡연 여부는 BMI보다는 스트레스, 음주, 직업, 사회경제적 요인, 정신건강, 또래/가족 환경 같은 외부 환경 요인에 더 크게 좌우될 가능성이 높다. 따라서 이 결과는 “BMI가 높을수록 흡연할 확률이 증가한다”는 **경향성(미세한 신호)**이 데이터에서 검출되었다는 의미이지, “뚱뚱하면 담배를 핀다”처럼 BMI가 흡연을 결정하는 핵심 변수라는 해석은 위험하다. 특히 표본이 큰 데이터에서는 효과가 작아도 p-value가 유의하게 나올 수 있기 때문에, 이 결과는 대규모 표본이 잡아낸 작은 상관 신호로 해석하는 게 가장 타당하다.
--- 

3. 신장 지표는 ‘흡연 효과’보다 교란(confounding) 통제가 결론의 품질을 결정한다
    신장 지표 (요단백·크레아티닌)는 흡연의 직접 효과보다 성별·체격 같은 교란요인의 영향이 크다. 
    특히 크레아티닌은 남성 비율 차이에 의해 흡연 효과처럼 보이는 착시가 발생할 수 있으므로,  
    단순 비교가 아니라 성별을 통제한 모델링이 필수적으로 요구된다.
